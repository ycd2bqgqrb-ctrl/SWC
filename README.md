# SWC
Shelly weather Controller
Automatische Steuerung von Shelly Aktoren mit daten der Wetterstation WS90 (Shelly BLU)
- Lüften
- Dachfenster Schliessen/Öffnen
- Markiesen und Rolladen Steuerung
- diverse Redundanzen/ Ausfallsicherungen
läuft lokal direkt auf dem Shelly
Entwickelt auf Shelly 2PM Gen3 und Shelly 1 Gen 3

Aktuellster test: 0004.1-standalone-logger-test.zip
